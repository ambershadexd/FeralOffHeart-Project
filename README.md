# The-OpenHeart-Project
Welcome! This is the official repository for The OpenHeart Project; a project which aims to create an easy-to-deploy, open-source FeralHeart source code repo. By the people, for the people. TOHP.

# The-FeralOffHeart-Project
An attempt at trying to make FeralHeart work offline.
The current goal is to remove everything in the game that requires networking so that it can bypass it, and store user data in the already existing folders for media and such.
