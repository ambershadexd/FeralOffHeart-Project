# FeralOffHeart-Project
A community project to make the Animal MMO "FeralHeart" work offline.

# Community:
Join our [Discord Server](https://discord.gg/Z3aMzFpwsy) if you plan on contributing.

# For Contributing:

General Recommendations:
- Try to keep Pull Requests for modifications/fixes not too large, try to divide it into multiple PRs. The same goes for new content that is fully functional, this is mostly for easier management.
- If you plan on adding new content that requires testing or still needs some work, make sure to make it a draft.

About AI Generated content:
- AI Usage is only allowed for research. Entirely vibecoded PRs will be rejected.
